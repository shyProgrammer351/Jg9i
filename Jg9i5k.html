 스레드를 시작하는 메서드

 바이트 스트림을 문자 스트림으로 변환하여 데이터를 읽어오는 클래스  

 출력 스트림에 데이터를 보내며, print, println 등 편리한 메서드를 제공  

 네트워크에 연결된 입력 스트림 가져오기  

 네트워크에 연결된 출력 스트림 가져오기  

 윈도우 리스너의 모든 메서드를 구현하여, 상속시 필요한 메서드만 재정의할 수 있는 클래스  

 프레임에 있는 종료(X) 버튼을 클릭하면 호출되어 실행하는 메서드  

 자식클래스가 부모클래스의 변수, 상수, 메서드를 모두 상속  

 자식 클래스에서 부모 인터페이스를 상속 받아 모든 메서드를 구현  

 상수와 추상 메소드로만 구성된 구조를 선언한 설계도  

 버튼 클릭이나 타이머 활성화 등의 이벤트 발생시 호출하는 메서드  

 try-catch-finally 문의 시작을 나타내고, 중괄호안에 예외가 발생할 가능성이 있는 코드를 포함
